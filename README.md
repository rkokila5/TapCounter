# Tap Counter — SwiftUI App

A simple iOS app built using **SwiftUI** where the user can tap a button to increase a counter. The app also includes a **Reset button** to set the counter back to zero. This project is part of my iOS learning and practice journey.

## ✨ Features

- Displays current tap count  
- “Tap Me” button increases the counter  
- “Reset” button sets count back to 0  
- Clean and minimal SwiftUI layout  
- Beginner-friendly and easy to extend  

## 🖼️ UI Layout

- Title: **Tap Counter**
- Count displayed using `Text("Count: \(count)")`
- Primary button to increment count
- Secondary red Reset button
- Styled using SwiftUI modifiers (spacing, padding, corner radius)

## 🛠️ Tech Stack

- SwiftUI  
- Xcode
